# CR-001：新手引导方向修正 + 分享链接导入纳入范围

| 字段 | 值 |
|---|---|
| 状态 | **approved**（用户 2026-11-22 Gate 2 复审反馈，明确授权："我看不懂的是我有一些 vless 或者 hy2 的代理，如何加入 clash 的代理，组成代理组，如何组成自动切换组，如何增删改查"） |
| 提出 | 用户 |
| 影响基线 | Gate 1 批准的非目标「分享链接导入列为 v1 非目标」；Gate 2 复审中线框 v2 的傻瓜模式（3 步端口向导） |

## 原方案

- 节点新增仅接受 mihomo YAML 片段；不解析 `vless://`、`hysteria2://` 等分享链接
- 傻瓜模式 = 「几个浏览器环境 → 每环境选节点」的端口分配向导（假定节点已导入）

## 新方案

- **新增分享链接解析**（服务端）：`vless://`、`hysteria2://`/`hy2://` 起步，textarea 一行一个批量粘贴，解析失败逐行报错不阻塞其余行；其他类型提示改用 YAML 片段
- **傻瓜模式重定义为「新手任务」**，按用户真实任务流组织：
  - 任务① 加节点：粘链接 → 解析预览（名称/类型/服务器/端口）→ 加入列表；下方节点清单支持删/查
  - 任务② 建组：选类型（自动切换 url-test「自动测延迟选最快的、挂了自动换」/ 手动 select「自己在 Clash 点选」/ 备用 fallback「按顺序用第一个活的」）+ 勾选成员 → 创建/更新；下方组清单支持改/删
  - 任务③ 绑端口：简化 listener 表（端口 + 绑定目标 + 复制 socks5 地址）
- 详细模式不变；「详细+说明」引导模式不变
- 模式名调整为：**新手任务 / 详细模式 / 详细+说明**

## 影响文件

- `docs/PRD.md`：范围、模式描述、验收条目
- `docs/ARCHITECTURE.md`：新增 `shareparse.go` 模块 + `/api/parse-links` 契约 + 链接→proxy 字段映射
- `docs/WIREFRAMES.md` + `design/wireframes/01,02,03`：任务模式重做、模式名更新
- `docs/TEST_PLAN.md`：链接解析单测 + 任务流 E2E
- `docs/PROJECT_DISCOVERY.md` §6、`AGENTS.md` 状态表

## 迁移/回滚

无持久化结构变化；回滚 = revert 本 CR 关联提交。重审门：Gate 2 复审（线框 v3）。
